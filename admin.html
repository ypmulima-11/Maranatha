Admin sign in

Sign in with a GitHub token that has Contents: Read and write access to the Maranatha repository. Your edits are saved straight to the repo and GitHub Pages republishes the site automatically (about 1 minute).

Tip: if sign-in fails here, open the page from the live site instead — ypmulima-11.github.io/Maranatha/admin.html (opening the file directly from disk can be blocked by the browser).

How to create a token (once)
  1. Open github.com and sign in as the repository owner.
  2. Go to Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  3. Click Generate new token, give it a name, and set an expiry.
  4. Under Repository access, choose Only select repositories and pick the Maranatha repo.
  5. Under Permissions → Repository permissions, set Contents to Read and write.
  6. Click Generate token and copy it here. You only need it once per browser.

Security: this token grants write access to your repository. It is stored only in this browser (localStorage) and never sent anywhere except GitHub. Sign out when you are done, and never use this page on a shared computer.
